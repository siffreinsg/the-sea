# Plan — Wallos (Thriller Bark)

Subscription tracker, complements Actual Budget. Follows
`docs/runbooks/add-a-service.md`; deltas only. Delete this doc when it lands.

**Node TB.** Financial data, so it sits with Actual Budget on the node with the
controlled kernel — the "sensitive → TB" half of the
[placement rule](../ADR/2026-07-22-placement-follows-benchmarks.md). It's a single
PHP container over SQLite; the disk never enters into it.

**Pin, resolved 2026-07-26:** `ghcr.io/ellite/wallos:5.4.2` (release v5.4.2, 2026-07-19).
Manifest index carries `linux/arm64` → runs on TB.

## 1. Ship dir — `thriller-bark/wallos/`

No host port — joins `edge`, reached by Caddy over container DNS on port **80**.

Two volumes, both stateful:

```yaml
    volumes:
      - wallos-db:/var/www/html/db
      - wallos-logos:/var/www/html/images/uploads/logos
```

`TZ=Europe/Paris`. `secrets.env` holds the OIDC client secret only.

## 2. Auth — OIDC, outcome (a)

Wallos gained OIDC and can take it entirely from env vars, which override the database
values at runtime — so this stays config-as-code rather than click-ops.

| var | value |
|---|---|
| `OIDC_ENABLED` | `true` |
| `OIDC_ISSUER` | `https://auth.siffreinsigy.me` — with the issuer set, Wallos fetches `/.well-known/openid-configuration` and discovers the rest |
| `OIDC_CLIENT_ID` / `OIDC_CLIENT_SECRET` | from `secrets.env` |
| `OIDC_PROVIDER_NAME` | `Authelia` |
| `OIDC_REDIRECT_URL` | set it **explicitly** rather than letting Wallos derive it behind the proxy |
| `OIDC_DISABLE_PASSWORD_LOGIN` | `true` — **after the first SSO login has created the account** |
| `OIDC_AUTO_CREATE_USER` | `true` for that first login, then off |
| `OIDC_REQUIRE_EMAIL_VERIFIED` | `true` |
| `OIDC_SCOPES` | default `openid email profile` |

`OIDC_CLIENT_SECRET_FILE` also exists if you'd rather mount the secret than env it; the
`secrets.env` + sops path is what everything else here does, so keep it.

**The trap to check first: `SSRF_ALLOWLIST`.** Wallos hardened against SSRF by filtering
the hosts it will call — that filter covers OIDC endpoints, not just webhooks and SMTP.
`auth.siffreinsigy.me` is a public name so it should pass, but if discovery fails with a
blocked-host error on first boot, that's the reason, and the fix is to add the host there
rather than to blame Authelia.

Caddy is a plain `reverse_proxy wallos:80`, no `forward_auth`. Redirect URI in
`thriller-bark/authelia/secrets.oidc.yml` must be exact — append to the clients array by
opening the file, never `sops set` on the `clients` path.

Check `wallos.siffreinsigy.me` has no existing Cloudflare record before deploying.

## 3. Currency rates

Wallos refreshes exchange rates from an external API and wants a key for the paid
providers; the free tier works without one. If you add a key it goes in `secrets.env`,
and the provider host may need to be in `SSRF_ALLOWLIST` for the same reason as above.

## Backups

**Critical tier** — this is finance data, the same class as Actual Budget, so it goes to
Mega as well as Proton.

`backup.sh` in the service dir dumping the SQLite DB inside the container (`sqlite3
.backup` or `VACUUM INTO`, **never a live `cp`**) to `/var/backups/the-sea/dumps/`. The
node's `run.sh` globs it up with no edits; the dumps dir is already a Backrest source.
Add the dump to TB's **critical** plan.

The logos volume is cosmetic and re-downloadable — mount it into bulk if you care, or
skip it and say so. The DB is the part that matters.

## Done when

Login lands on Authelia with the password form gone, a subscription saves and survives a
container recreate, the monthly total renders, and the dump file appears in a TB critical
snapshot.
