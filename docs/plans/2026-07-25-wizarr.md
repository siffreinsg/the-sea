## Auth — native, with bypasses

Wizarr has its own admin login and authenticates end users through Plex. Guests must
reach the invite pages **without** hitting the Authelia portal, so forward-auth
protects the admin surface only.

**Verify the invite/join path prefix in 2025.7.8's docs before writing this** — it has
changed between releases. Then, per §3b(b), with every branch in its own `handle {}`:

```caddyfile
	@wizarr host wizarr.siffreinsigy.me
	handle @wizarr {
		@wizarr_public path /j/* /join* /setup* /static/*   # ← confirm against the pinned version
		handle @wizarr_public {
			reverse_proxy 100.64.0.1:5690
		}
		handle {
			forward_auth 127.0.0.1:9091 {
				uri /api/authz/forward-auth
				copy_headers Remote-User Remote-Groups Remote-Email Remote-Name
			}
			reverse_proxy 100.64.0.1:5690
		}
	}
```

Test both sides explicitly: an invite URL in a private window must render for an
anonymous visitor, and `/` must 302 to the portal.
