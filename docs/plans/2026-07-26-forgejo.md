# Plan — Forgejo (Going Merry)

Self-hosted git forge. Follows `docs/runbooks/add-a-service.md`; deltas only. Delete this
doc when it lands.

**Node GM.** Git repositories are disk-I/O — pack files, `git gc`, clones — which is the
GM half of the [placement rule](../ADR/2026-07-22-placement-follows-benchmarks.md).

**Pin, resolved 2026-07-26:** `codeberg.org/forgejo/forgejo:16.0.1` (released
2026-07-21; manifest index inspected, carries `linux/amd64`). Codeberg's registry, not
GHCR or Docker Hub — that's where upstream publishes. **v16 is a major release**; read its release notes on deploy day, and don't
apply anything written for v11 or v15.

**No Actions runner.** Decided: Forgejo is useful as a git host on day one, and a runner
needs a registration token from an already-running instance, so it could never be in this
first deploy anyway. Tracked in `docs/FUTURE.md`. When it does land, it goes on TB — GM is
the 322-events/s single-thread node and builds would crawl — and it gets the Docker socket,
which on GM means no AppArmor and no userns-remap.

## 1. Ship dir — `going-merry/forgejo/`

Bind `100.64.0.1:3080` → container 3000. GM's taken ports: 3000 grafana, 3100 loki, 3200
dawarich, 6868 profilarr, 8095 your_spotify, 8428 victoriametrics, 9898 backrest, 11011
cleanuparr, 3050 karakeep once it lands.

Add a `gm-relay` listener on `13080` and a row in [REFERENCE](../REFERENCE.md#gm-relay),
`tag:gm:3080` to the TB→GM allowlist in `thriller-bark/headscale/acl.hujson`, and rows in
REFERENCE's ACL port table and Web UIs table — main Caddy is bridge-networked and can't
dial the mesh directly
([why](../ADR/2026-07-29-caddy-relays-mesh-services-to-containers.md)).

**Do not publish the SSH port (2222).** Decided: HTTPS-only, see below.

`USER_UID=1000` / `USER_GID=1000`, and one volume at `/data` holding repositories, the
SQLite DB, LFS and avatars.

Config is `app.ini`, generated on first run and then owned by the container. Forgejo reads
`FORGEJO__section__KEY` env vars over it, which is the config-as-code path — use those for
anything that matters rather than editing the file in the volume:

| var | value |
|---|---|
| `FORGEJO__server__ROOT_URL` | `https://forgejo.siffreinsigy.me/` — **trailing slash**, and set it explicitly; every clone URL and OAuth callback is built from it |
| `FORGEJO__server__DISABLE_SSH` | `true` |
| `FORGEJO__service__DISABLE_REGISTRATION` | `true` |
| `FORGEJO__service__ALLOW_ONLY_EXTERNAL_REGISTRATION` | `true` |
| `FORGEJO__database__DB_TYPE` | `sqlite3` |
| `FORGEJO__security__INSTALL_LOCK` | `true` once set up — leave it off for the first boot so the installer runs |

**No `secrets.env`, so no `pre_deploy`.** The OIDC client secret is entered through the
admin CLI into Forgejo's own database, not through env (see below), and nothing else here
is sensitive. If that changes, the `pre_deploy` starts with `umask 077` like every other
one in `resources.toml`.

## 2. Git transport — HTTPS only

Decided. TB's port 22 is the host's own SSH and GM only exposes 4747, so an SSH port for
git would mean a second deliberate firewall exception on top of Syncthing's 22000. It buys
nothing a personal access token doesn't already give a single-user forge.

```bash
git remote add origin https://forgejo.siffreinsigy.me/<user>/<repo>.git
# username = your Forgejo user, password = a PAT from Settings → Applications
git config --global credential.helper store   # or the OS keychain
```

Since auth is OIDC (outcome **a**) and Caddy stays a plain `reverse_proxy
host.docker.internal:13080`, there is **no
`forward_auth` to bypass** for `*.git/*` — git's own Basic auth reaches Forgejo untouched.
This is the one place where picking OIDC over forward-auth also removed an edge special
case; if this app were ever moved to outcome (b), the git paths would need explicit
bypasses.

Check `forgejo.siffreinsigy.me` has no existing Cloudflare record before deploying.

## 3. Auth — OIDC, outcome (a)

Forgejo has no env var for the OIDC provider. It is an *authentication source*, added once
after the instance is up — GUI (Site Administration → Authentication Sources) or CLI:

```bash
docker exec -it forgejo forgejo admin auth add-oauth \
  --provider=openidConnect --name=authelia --key=forgejo \
  --auto-discover-url=https://auth.siffreinsigy.me/.well-known/openid-configuration
```

**The secret goes in interactively, never as `--secret=` on that line** — that's the
runbook rule, and this command is exactly the case it was written for. If Forgejo's CLI
gives no prompt, prefix the line with a leading space so `HISTCONTROL=ignoreboth` keeps it
out of history, and treat that as the backstop it is.

Redirect URI — the `authelia` in the path is the `--name` above, so the two must match:
```
https://forgejo.siffreinsigy.me/user/oauth2/authelia/callback
```
`client_secret_basic`, and `require_pkce: true` with `S256` — Forgejo supports it, so
unlike `profilarr` and `karakeep` this client gets PKCE on.

Order matters: create the admin account through the first-run installer, add the auth
source, log in once through Authelia to link it, **then** set
`DISABLE_REGISTRATION`/`INSTALL_LOCK` and confirm the local password form is gone.

## Backups

**Critical tier** — source code is the sensitive-data class the runbook names, and Mega
gives a second provider.

`backup.sh` in the service dir running `forgejo dump` inside the container, output into
`/var/backups/the-sea/dumps/` with the usual atomic `.part` + `mv`. `forgejo dump` bundles
repositories, the database, LFS and attachments into one archive — which is why this needs
no separate volume mount into Backrest, unlike the other GM apps. **If the archive leaves
the container via `docker cp`, `chmod 600` it** — the umask doesn't carry across.

`forgejo dump` writes a temp copy of everything before it archives, so it needs free space
roughly the size of the instance. On GM's 99 G ploop that's fine now; watch it if the
forge grows.

Add the dump to GM's **critical** plan.

## Done when

Login goes through Authelia with local registration off, a repo clones and pushes over
HTTPS with a PAT from a machine that isn't on the mesh, and a `forgejo dump` archive
appears in a GM critical snapshot.
