# Leantime — self-hosted task/project manager

Replaces MS Planner for personal task/deadline tracking. Solo use, 4 clients (2 with
several parallel projects), needs subtasks/checklists and a cross-project "due this
week" view. Time-tracking stays in the existing Excel sheet. Planner stays only as a
manual downstream mirror for the employer's team-visibility requirement.

On TB despite the MySQL/MariaDB dependency (deviates from TB/GM's DB-app split) —
the DB stays tiny for solo use, judged not worth the gm-relay indirection.
